# Frida0xKit

> A modular toolkit for Android runtime instrumentation, reverse engineering, debugging, and security research.

Frida0xKit is a curated collection of reusable Frida scripts, runtime hooks, analysis utilities, and practical tooling for investigating Android applications at runtime.

The project is designed as a growing toolbox rather than a collection of one-off scripts, with reusable components organized around Java, native, networking, SSL/TLS, runtime analysis, and debugging workflows.

## Features

* Java and Android framework hooks
* Native function instrumentation
* HTTP/HTTPS and networking inspection
* JSON and runtime data tracing
* SSL/TLS instrumentation
* Anti-debugging research utilities
* Runtime DEX and native analysis
* Reusable Frida helpers and templates
